# Игра: <название>

Игровой набор — всё, что знает про игру и не зависит от канала и стиля. Копия этого файла — `src/games/<игра>/GAME.md` (образцы — `src/games/hearthstone/GAME.md`, `src/games/lol/GAME.md`). Читает навык направления в разделе «Данные игры».

## Что где

| Что | Где |
|---|---|
| Данные, типы, сгенерированные id, проверки сцен и `qa` канала, словарь | `data/` (импортирует только `src/core` и себя) |
| Сцены игры (компонент + `defineScene`) и их детали | `scenes/`, `scenes/parts/` (импортирует `src/core`, `data/` и стиль студий этой игры) |
| Образец данных для демо, витрин, стендов | `fixtures/` (берут только студии) |
| Загрузчики и скрипты игры | `scripts/games/<игра>/` |
| Картинки | `public/<игра>/…` |
