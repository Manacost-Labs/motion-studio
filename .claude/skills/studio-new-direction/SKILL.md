# Новое направление студии

Все команды — из `video/`. Сначала — навык `studio` (общие правила, траты, коммиты) и `video/STUDIO.md` (слои, правила импортов, реестр сцен, «куда класть новое»). Решения о вкусе, названии канала, голосе и источниках данных принимает пользователь — неизвестное спросить **одним списком**.

## Из чего собирается направление

Этап B переезда закрыт: всё общее уже вынесено, новое направление **собирается из слоёв, а не копируется** из `manacost-youtube`.

| Слой | Что даёт | Что делает направление | Образец |
|---|---|---|---|
| `src/core` | движок под голос (`VoicedVideo`, `calcVoiced`), реестр сцен (`defineScene`, `defineChannel`, `ConfigOf`), звук, эффекты, подгонка текста, проверки (`qaOf`, `VIDEO_LIMITS`), регистрация (`voicedCompositions`) | ничего не копирует, только импортирует | `src/core/README.md` |
| `src/looks/<стиль>` | оформление: фон, переход, субтитры (`VoicedLook`), детали, сцены без игры (вступление, тезисы, картинка, разделитель, финал) | берёт готовый стиль или заводит новый — только после стиль-кадров и «да» | `src/looks/compendium/` |
| `src/games/<игра>` | `GAME.md`; `data/` (типы, id, словарь, проверки и `qa` канала), `scenes/` (сцены игры в стиле канала), `fixtures/` (образец данных для демо) | игровой набор новой игры | `src/games/hearthstone/`; у LoL уже есть `src/games/lol/` (`GAME.md`, `data/`) |
| `src/brands/<канал>` | `channel.ts`: имя, сайт, ссылки, логотип, финал, голос и музыка (`YT_BASE`), подвал описания, юридический блок `legal` (`BrandLegal`: `disclaimer`, `policyUrl`, `forbidden`, `forbiddenInVideo`, `forbiddenInTags`, `required`) | бренд нового канала | `src/brands/manacost/channel.ts` |
| `src/studios/<dir>` | тонкая сборка: `channel.ts` (`defineChannel({look, brand, game, context, fields, scenes, qa})`), `videos.ts`, `Root.tsx`, `index.ts`, `README.md`, `pronounce.json`, `BRIEF.md`, ролики `<prefix><тема>/` | студия направления | `src/studios/manacost-youtube/` (смотреть, не импортировать) |

Новая сцена — файл сцены (компонент + `defineScene`) и строка в `scenes` канала. Тип конфига выводится из канала (`ConfigOf<typeof channel>`): сцена Hearthstone в ролике LoL не пройдёт `tsc`. Правила импортов (стиль не знает игры и бренда, сцены игры берут только стиль своих студий, ролик видит только `../channel`) проверяет `check-layers` — Stop-хук и pre-commit блокируют нарушения.

## Команда-скаффолд

`node scripts/new-direction.mjs --key <ключ> --dir <канал>-<площадка> --game <игра> --brand <канал> --look <compendium | new:<имя>> --prefix <префикс>- --port <порт> [--title "<название>"] [--dry]` — сначала с `--dry` (план), потом без него. Создаёт строку реестра, папку студии (`index.ts`, `Root.tsx` с обложкой и витриной-заглушкой `<префикс>showcase`, `channel.ts`, пустой `videos.ts`, `README.md`, `pronounce.json`, `BRIEF.md`), игровой набор и бренд канала с `TODO` (если их ещё нет), при `new:<имя>` — стиль-заглушку `src/looks/<имя>/` (README, `look.tsx`, `showcase/README.md`), заготовку навыка и вкуса (если их нет), дописывает `studio:<ключ>` в `package.json` (сказать пользователю) и печатает «Дальше: …». Сцены канала: у готового стиля — сцены стиля и игры (сцена игры важнее сцены стиля того же вида), у нового — пустой список с `TODO`. Ключ или папка студии уже есть — ошибка, ничего не пишется.

Скаффолд создаёт только заготовки: `GAME.md`, `data/types.ts`, `data/pronounce.json`, `scenes/index.ts` игры (если её не было), бренд с `TODO`, `legal` с пустыми `forbidden`/`forbiddenInVideo`/`forbiddenInTags` и `required: true`. `ids.ts` и снимок данных пишет **загрузчик игры** (шаг 2, `scripts/games/<игра>/`), не скаффолд. Стиль-заглушка `new:<имя>` — пустое место под стиль, не стиль: до «да» на стиль-кадрах её не наполнять (шаг 4).

**Пробный запуск и откат** (проверка навыка, «посмотреть, что создаст»): в конце вывода скаффолд печатает «Откат — удалить только это» — список новых папок и файлов. Откатывать ровно по нему: удалить эти пути, в `src/studios/studios.json` — одну строку своего ключа, в `package.json` — одну строку `studio:<ключ>`. **Нельзя** удалять `studios.json` или `package.json` целиком и возвращать их из git (`git checkout`/`git restore`): `studios.json` — единственный реестр студий (не генерируется; до коммита он untracked — это не мусор), в `package.json` есть незакоммиченные правки — откат из git их стирает. Проверка отката: `node scripts/studios.mjs` — прежний список студий; `git diff -- package.json` — нет строки `studio:<ключ>`, остальные правки на месте.

## Что должно быть готово до первого ролика

- Слои `core`, `looks`, `games`, `brands` и реестр сцен — готовы (этап B). Шаблон направления — это `channel.ts` студии поверх них; копия «Компендиума» с Hearthstone внутри запрещена.
- Решения пользователя: стиль-кадры, название канала, голос, источник статистики.
- Одобренное демо всех сцен и эталоны; навык направления прошёл проверку слабой моделью.
- Первый ролик — тот, что не зависит от сторонней статистики (для LoL — обзор патча по официальным данным).

## Что делает скаффолд (и как вручную, если без него)

1. Строка в `src/studios/studios.json`: `{"key", "dir", "kind": "youtube", "title", "game", "brand", "look", "idPrefix", "port", "freeze": "golden"}` — ключи и порты существующих студий не трогать, порт — следующий свободный (3003…). Поля `game`, `look`, `brand` решают, какие слои студия (и сцены игры) вправе импортировать.
2. Бренд канала `src/brands/<канал>/channel.ts` и игровой набор `src/games/<игра>/` (`GAME.md`, `data/`, `scenes/`, `fixtures/`) — см. таблицу «Из чего собирается направление».
3. Папка `src/studios/<dir>/` по образцу `src/studios/manacost-youtube/` (смотреть, не импортировать): `channel.ts` (`defineChannel`, тип конфига `ConfigOf<typeof channel>`, `LIMITS` = пороги игры + `VIDEO_LIMITS`), `videos.ts` (`VIDEOS`), `Root.tsx` (ролики из `videos.ts` через `voicedCompositions(channel, Thumb)`), `index.ts`, `README.md` (паспорт: назначение, бренд, игра, стиль, навык, `freeze`, служебные композиции), `pronounce.json` (бренд канала), `BRIEF.md`.
4. `package.json` → `"studio:<ключ>": "remotion studio src/studios/<dir>/index.ts --port <порт>"` — это правка конфигурации: сказать пользователю заранее.

6. `video/taste/<ключ>.md` (по `templates/taste.md`) и `qa/taste/<ключ>/`.
7. Записи OBS новой игры — свой профиль и свой README в `recordings/<игра>/`.
8. Шаги 7–9 чек-листа.

## Правила

- Не копировать шаблон «Компендиум» и не импортировать из `manacost-youtube` и чужих роликов: общее — в `src/core`, стиль — в `src/looks/<стиль>`, игра — в `src/games/<игра>`, бренд — в `src/brands/<канал>`.
- Стиль не знает игры и бренда: бренд, гербы, места и строки итогов сцены получают через `context` канала.
- Вкус нового направления — только из его стиль-кадров; правила «Компендиума» (пергамент, сукно, сургуч) и рекламы HP не переносить. Общее — `video/TASTE.md`.
- Цифры — только из источника с подписью. Без письменного разрешения источника статистики — без тир-листов и рейтингов.
- Кредиты, коммиты, эталоны — по правилам навыка `studio`.
