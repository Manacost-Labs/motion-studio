# Пример конфига обзора функции (`FeatureSpotConfig`)

Образец — закреплённый ролик `src/studios/hp-features/feature-matchups/config.ts` (его папку не правим: копируем в `feature-<тема>`, удаляем `feature-<тема>/ref/`). Типы — `src/studios/hp-features/template/FeatureSpot.tsx` и `src/hearthpulse/scenes.tsx` (`HookProps`, `FeatureProps`, `PanelSpec`, `BackdropSpec`, `EndCardProps`). Ниже — тот же конфиг с пояснениями.

```ts
import {RIGHT_X} from '../../../hearthpulse'; // левый край правой колонки в 16:9
import {FeatureSpotConfig} from '../template/FeatureSpot';

export const MATCHUPS: FeatureSpotConfig = {

  logo: {tagline: 'Статистика и аналитика Hearthstone'},
  // ── Сцены функции: 1–2 штуки по 110–150 кадров; стыки — на сильные доли (beats.mjs) ──
  features: [
    {
      dur: 150, // длина сцены в кадрах (30 к/с)
      kicker: 'Стандарт · Вольный', // надзаголовок с ромбами, до ~30 знаков
      title: 'Матчапы', // заголовок: до 3 слов

        focus: '45% 50%', // какая часть арта в кадре

        {
```

## Что ещё бывает в конфиге

- `carousel: {kicker: 'И ещё', items: [{src, size, title, sub}, …]}` — разделы по очереди выезжают в центр, 30 кадров на раздел.
- У панели: `scroll: {start, end?, dist: {v, h}}` — прокрутка страницы внутри рамки; `hover: {at, cursor, layers}` — курсор наводится, проявляются слои снимка hover-состояния (нужны два снимка одного места: без наведения и с наведением); `from: 'bottom' | 'left' | 'right' | 'zoom' | 'scroll'`.
- У сцены: `live: …` — живой фон из Higgsfield вместо статичного арта (кредиты — смета и «да»).

## Правила текста (`video/BRAND.md`, «Текст»)

- Одна мысль на сцену. Заголовок до 3 слов, подпись до 6, надзаголовок до ~30 знаков.
- Цифры — только реальные, со скриншотов сайта, без округлений и «роста винрейта».
- Не обещать побед, Легенды, роста рейтинга. Не называть бесплатное эксклюзивом подписки.
