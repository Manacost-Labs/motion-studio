# Примеры заполнения конфига (из готового ролика `yt-legend-decks-sep26`)

Заготовка `scripts/yt-new.mjs` уже содержит все сцены. Автор заполняет `TODO` и переписывает `vo`. Ниже — как это выглядит готовым, на настоящих данных.

## 1. Колода: абзацы статьи → блок `deck(...)`

**Было в статье** (`article.json`, `decks[].paragraphs`):

> Самая популярная колода и колода, против которой нет жесткой контры, — все это Друид на атаке. Архетип слегка уступает только трем агро колодам: Зи Шаману, ДК Нечестивости и Чистому Паладину. В остальном у нее нет слабых сторон.
>
> Сборок у Друида на атаке очень много. В основном они отличаются составом лейтгейма: кто-то не использует его вовсе, кто-то использует только Меритру из Сна, а кто-то берет полный набор драконов с Наралексом. В последнее время также стал популярным Жизнецвет — сборки с ним сейчас выглядят лучше всего.
>
> Однако лейтгейм — не главное в этой колоде. Главное — найти Паучка на 1-й ход и разогнать эффект Заражения кладовой, чтобы как можно раньше задавить противника большими статами.

**Стало в конфиге:**

```ts
deck(3, {
  // 2–3 тезиса: что зритель должен запомнить. text ≤ 28 знаков, detail ≤ 45. at — кусок vo ДОСЛОВНО
  points: [
    {text: 'Самая популярная колода', detail: 'Жёсткой контры против неё нет', at: 'Самая популярная'},
    {text: 'Лучшие сборки', detail: 'С Жизнецветом', at: 'стал популярен'},
    {text: 'Главное — темп', detail: 'Паучок на первый ход и Заражение кладовой', at: 'найти Паучка'},
  ],
  // матч-апы — только те, что названы в статье. verdict: 'good' — колода сильнее, 'bad' — слабее
  vs: [
    {cls: 'Шаман', verdict: 'bad', label: 'Зи Шаман', at: 'слегка уступает'},
    {cls: 'Рыцарь смерти', verdict: 'bad', label: 'ДК Нечестивости', at: 'слегка уступает'},
    {cls: 'Паладин', verdict: 'bad', label: 'Чистый Паладин', at: 'слегка уступает'},
  ],
  // текст диктора: пересказ, разговорно, числа словами («1-й ход» → «первый ход»), у топ-3 — [pause] перед названием
  vo:
    'Третье место — [pause] Друид на атаке. Самая популярная колода меты, и жёсткой контры против неё нет: она слегка уступает только трём агро колодам — ' +
    'Зи Шаману, ДК Нечестивости и Чистому Паладину. Сборок у Друида очень много, и отличаются они в основном лейтгеймом: кто-то обходится без него, ' +
    'кто-то берёт только Меритру из Сна, а кто-то — полный набор драконов с Наралексом. В последнее время стал популярен Жизнецвет, и сборки с ним сейчас выглядят лучше всего. ' +
    'Но главное в этой колоде не лейтгейм. Главное — найти Паучка на первый ход и разогнать эффект Заражения кладовой, чтобы как можно раньше задавить соперника большими статами.',
  // карты под голос: камера наезжает, карта поднимается. id — из заготовки (она берёт их из статьи). at — как карта названа в vo
  // ink: true — красное перо обводит карту: только то, что диктор называет главным/лучшим, 2–3 на колоду
  cards: [
    {id: 'CATA_140', at: 'Меритру из Сна'},
    {id: 'EDR_844', at: 'Наралексом'},
    {id: 'MEND_042', at: 'Жизнецвет', ink: true}, // «выглядят лучше всего»
    {id: 'JAIL_202', at: 'Паучка', ink: true}, // «главное — найти Паучка»
    {id: 'JAIL_200', at: 'Заражения кладовой', ink: true},
  ],
}),
```

Что важно:
- `at` — подстрока `vo` (регистр не важен). Переписал `vo` — проверь, что каждая фраза из `at` в нём осталась; `yt-qa` покажет потерянные.
- Карта в `at` может стоять в любом падеже, как сказал диктор («Наралексом»), — это просто кусок текста.
- Тезис не пересказывает абзац, а называет вывод: «Главное — темп», а не «В этой колоде главное найти Паучка».
- Цифры в тезисах можно («28 урона за ход»), в `vo` — только словами («двадцать восемь урона»).

## 2. Сильное начало `hook`

```ts
// самый яркий факт статьи: из абзаца «Семь драконов на столе — 28 урона, с Хронолордом Дейосом — 48»
{
  kind: 'hook',
  id: 'hook',
  value: 48, // число на экране — из статьи, не выдумывать
  label: 'урона за один ход',
  at: 'Сорок восемь', // на этой фразе число отсчитывается
  cards: [{id: 'CATA_999'}, {id: 'DINO_402'}, {id: 'TIME_064'}], // 2–3 карты веером (id — из article.json колоды)
  punch: {text: 'и это всего лишь 15-е место', at: 'И это', cls: 'Чернокнижник'}, // добивка внизу и герб класса
  vo: 'Сорок восемь урона за один ход. [pause] [curious] И это всего лишь пятнадцатое место.',
},
```

Как выбрать факт: самое большое число или неожиданность из статьи (урон за ход, «колода за 1 680 пыли в топ-4», «без контры»). Формула фразы: **факт. [pause] [curious] добивка про место**. Если числа нет — `value` всё равно нужен: возьми место, стоимость в пыли или число колод.

## 3. Вступление `intro`

```ts
{
  kind: 'intro',
  id: 'intro',
  kicker: 'Аметистовая крепость · сентябрь 2026', // дополнение · месяц год
  title: '15 колод\nдля Легенды', // две строки, \n — перенос
  sub: 'Стандарт · с 15-го места до 1-го',
  classes: articleClasses(article), // гербы — сами из статьи
  tease: articleTease(article), // размытые постеры топ-3 — сами
  teaseAt: 'на вершине', // намёк на лидера: в этот момент появляются размытые постеры топ-3 (без поля — с середины речи)
  vo:
    '[warmly] До конца сезона — десять дней. И вот пятнадцать колод, с которыми ещё можно ворваться в Легенду. ' +
    'Воин сейчас на вершине... [curious] но какой именно? Узнаем в самом конце.',
},
```

Интригу держать: кто на первом месте — не говорить до конца ролика. Перечитай текст на грамматику: «несмотря на господство Воина», а не «господства».

## 4. Врезки в колоду (по желанию)

```ts
inserts: [
  // разбор комбо на месте постера, пока звучит фраза at … to; числа — только из статьи
  {
    kind: 'combo',
    at: 'Комбинация состоит',
    to: 'зачем тут МАТРИАРХ',
    title: 'Комбо из двух карт',
    cards: [
      {id: 'CATA_999', at: 'Земляной дракон'},
      {id: 'DINO_402', at: 'Маска нетопыря'},
      {id: 'TIME_064', at: 'Хронолорда Дейоса'},
    ],
    results: [
      {value: 28, label: 'урона в конце хода — семь драконов', at: 'двадцать восемь'},
      {value: 48, label: 'если поставить Хронолорда Дейоса', at: 'сорок восемь'},
    ],
  },
  // геймплей: только своя запись или CC BY с автором (credit обязателен)
  {kind: 'clip', at: 'Всю неделю', to: 'Комбинация состоит', src: 'clips/<файл>.mp4', start: 35, crop: [430, 0, 1260, 1080], caption: 'Пример хода', credit: 'Геймплей: <автор> · YouTube · CC BY'},
],
```

## 5. Разделители и финал

```ts
divider(10, 6), // прямо перед deck(10, …): «Топ-10», медали 10…6. Заготовка ставит их сама
divider(5, 1),
manacostOutro({kicker: 'Итоги · Аметистовая крепость · сентябрь 2026', title: 'Все 15 колод'}), // таблица → конечная заставка
```

Свой текст финала — `manacostOutro({…, vo: '…'})`, но в нём должно остаться «Подписывайтесь» (на этой фразе таблица уступает заставке).

## 6. Текст диктора: как писать

| Плохо (как в статье) | Хорошо (для голоса) | Правило |
|---|---|---|
| на 1-й ход | на первый ход | числа и порядковые — словами |
| 28 урона | двадцать восемь урона | |
| против трех агро колод: Зи Шамана, ДК Нечестивости и Чистого Паладина. В остальном у нее нет слабых сторон. | она слегка уступает только трём агро колодам — Зи Шаману, ДК Нечестивости и Чистому Паладину. | одна мысль — одна фраза; пустые фразы («в остальном слабых сторон нет») выкидывать |
| `[excited]` Пятнадцатое место! | Пятнадцатое место — ОТК Чернокнижник. | без `[excited]` (диктор кричит) и без серий «!» |
| Hearthstone, HSReplay | Хартстоун, статистика | латиницу диктор читает по-английски |
| ДК, ОТК, ДХ | (оставить, но добавить в `pronounce`) | `pronounce: {ДК: 'дэ-ка', ОТК: 'о-тэ-ка'}` |
| На втором месте находится Пират Воин. | Второе место — [pause] Пират Воин. | у топ-3 пауза перед названием — её «держит» заставка места |

Длина: 20–45 секунд на колоду (≈ 300–650 знаков `vo`). Топ-3 и колоды с комбо — длиннее, середина списка — короче.
