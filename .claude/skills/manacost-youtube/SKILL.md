# YouTube-ролики Манакоста по Hearthstone

Студия `video/src/studios/manacost-youtube` — тонкая сборка: канал `channel.ts` (стиль «Компендиум», игра Hearthstone, бренд Манакост; тип конфига `YtConfig`, каркас ролика по статье, пороги `LIMITS`), список роликов `videos.ts`, ролики `yt-<тема>/` (их `config.ts` импортирует только `../channel`). Справочник сцен и полей — паспорт студии `video/src/studios/manacost-youtube/README.md`. Код — в общих слоях: движок `video/src/core`, стиль `video/src/looks/compendium`, игра `video/src/games/hearthstone` (`GAME.md`), бренд `video/src/brands/manacost`. Готовый образец — `yt-legend-decks-sep26/config.ts`; как заполнять, на его примерах — **[examples.md](examples.md)**. Бренд — только Манакост (без рекламы HearthPulse). Все команды — из `video/`.

Сначала прочитай (не больше трёх): этот файл + `examples.md`; `video/TASTE.md` и `video/taste/manacost-hs.md` (вкус: одобрено, пробы, отвергнуто). Общие инструменты, траты, коммиты — навык `studio` (`.claude/skills/studio/SKILL.md`).

## Как заполнять конфиг (подробно — examples.md)

- **Порядок сцен** заготовка ставит сама: `hook` → `intro` → колоды с последнего места → `divider` перед №10 и №5 → №3–№1 → `manacostOutro`. Не переставлять.
- **`at`** (и `to`, `teaseAt`) — кусок текста `vo` дословно, 1–4 слова: элемент появляется, когда диктор это говорит.
- **Тезисы** `points`: 2–3 (не больше `LIMITS.pointsMax` = 3); `text` — вывод, а не пересказ, до `LIMITS.pointText` = 28 знаков (длиннее — две строки); `detail` — до `LIMITS.pointDetail` = 52 знаков, короче — лучше. Пороги — `LIMITS` в `channel.ts` студии (пороги колоды — `DECK_LIMITS` в `video/src/games/hearthstone/data/audit.ts`); менять только в источнике.
- **Матч-апы** `vs` — только названные в статье (нет в статье — `vs: []`); их `at` — кусок `vo`, где диктор о них говорит.
- **Карты** `cards` — заготовка берёт из упоминаний. `ink: true` — не больше `LIMITS.inkMax` = 3 на колоду (0 — норма), только у карт, которые диктор называет главными, лучшими, ключевыми.
- **`teaseAt`** во вступлении — фраза-намёк на лидера («на вершине»): появляются размытые постеры топ-3.
- **Числа** на экране — только из статьи или `meta.json`; в `vo` — словами. Цифра из `meta.json` — с источником в тексте: «винрейт 54,8 % по данным HSReplay в Легенде». Колоды с `reliable: false` (меньше тысячи игр) — без цифр.
- **Произношение:** словарь игры `src/games/hearthstone/data/pronounce.json` (термины: `"ДК": "дэ-ка"`, имена с апострофом) и словарь бренда `src/studios/manacost-youtube/pronounce.json` (пока пуст) подмешиваются во все ролики. Новое сокращение, карта или имя Hearthstone — **в словарь игры**; слово канала — в словарь бренда; в `pronounce` конфига — только слова этого ролика.
- **`ambience`**, «живой» арт и другие пробы — по статусу в `video/taste/manacost-hs.md`: пока «проба» — только с согласия пользователя.
- **Обложка** `thumb`: `title` — две строки, каждая ≤ `LIMITS.thumbLine` = 14 знаков (`\n` не считается); `badge` — «Октябрь 2026»; `cards` — три разные карты №2, №3, №1 (заготовка ставит сама). Варианты для «Тест и сравнение» — `thumbs: [{hook: …}, {badge: …}]` (поля поверх `thumb`, всего до 3), лист читаемости — `yt-thumb.mjs`; выбор — за пользователем.
- **`seo`**: `lead` — первая строка описания (о чём ролик, не повтор названия, ≤ 150 знаков), `hashtags` — до трёх без «#», `tags`, `titles` — варианты названия (≤ 70). Тон спокойный, без «!!!».
- **Врезка геймплея** `clip` — только своя запись (`rec.mjs take`) или CC BY с согласием (`eyes.mjs cut`): паспорт `<клип>.json` рядом обязателен. `probe: true` — пробная врезка «для примера», не для выпуска (`release.mjs` даст ❌).

## Статистика меты (`meta.json`)

`node scripts/meta-stats.mjs yt-<тема>` (`yt-new` запускает сам) — Koloda Hearthstone API (токен `KOLODA_API_TOKEN` в `video/.env`, необязателен). Для каждой колоды статьи — архетип HSReplay по совпадению карт: `winrate` и `popularity` (% игр в Легенде EU за 7 дней), `deck.winrate`/`deck.games` самой сборки, `best`/`worst` матч-апы, `mulligan`, `trend`. Использовать: тезис с цифрой — только если в `vo` это сказано; матч-апы — 1–2 из `best`/`worst`, если статья молчит; сцена `mulligan` — из `mulligan`. Статья важнее: расхождение — пользователю.

## Геймплей и референсы

Свои записи OBS (`rec.mjs`), поиск геймплея с правами (`eyes.mjs find` — YouTube и клипы Twitch категории Hearthstone), разбор чужих роликов (`eyes.mjs look`, `scenes`), нарезка (`eyes.mjs cut`) и права — `.claude/skills/studio/reference/eyes-ears.md`.

## Проверки качества

Полный список и флаги — навык `studio`, раздел «Проверки качества», и `.claude/skills/studio/reference/quality.md`. Для этого направления:

- до голоса: `yt-qa --no-video` → `judge.mjs` (матч-апы, тезисы, фразы против статьи; `agent` — без ключей, `jev` — только пилот по ключу `TYPESAFE_API_KEY` в `video/.env`, данные уходят в США — только публичный текст статьи и сценария) → `yt-lint` → `yt-board`;
- после правки канала или общих слоёв (`src/core`, `src/looks/compendium`, `src/games/hearthstone`, `src/brands/manacost`): `node scripts/yt-golden.mjs yt-legend-decks-sep26` и `yt-template-demo`, плюс `--dir qa/golden-joints` (стыки) — 0 изменений, если вид не должен был меняться; `--approve [сцена…]` — только после «да» (со сценами переснимаются только их кадры);
- после рендера: `yt-qa` по видео (громкость, цвет bt709, рывки, тишина) → `yt-thumb` (обложки и лист читаемости) → `yt-export` → `release.mjs`;
- после публикации (по желанию): `node scripts/yt-metrics.mjs <id> <csv из YouTube Studio>` — удержание по сценам.

## Готово, когда

**`node scripts/release.mjs yt-<тема>` — ни одного ❌.** Кроме того: `yt-qa` — 0 ошибок и 0 предупреждений (заметки допустимы); `yt-lint` — 0 находок; `ears.py` — без «голос поднят»; ни одного `TODO`; голос у всех сцен, кроме разделителей; пользователь посмотрел фрагмент и сказал «да»; громкость −14 ±1 LUFS; `description.txt` начинается с «0:00». Без ❌ вердикт — «Технически готово — ждёт человека»: ручные пункты `out/yt-<тема>/release.md` пройти с пользователем, и только по его слову — `node scripts/release.mjs yt-<тема> --approved` («Готово к выпуску (одобрено человеком)»). Коммит — предложить, делать только по слову пользователя.

## Грабли Hearthstone

- Карты, которых нет в колоде, камера пропускает — их показывает карточка «упомянута»; порядок карт на постере не угадывать по стоимости — `poster-fit.mjs`.
- Обложку и кадры — всегда с точкой входа `src/studios/manacost-youtube/index.ts` (иначе подставится студия рекламы).
- Общие грабли (transform вместо left/top, 60 к/с, кириллица в PowerShell, prettier) — `.claude/skills/studio/reference/pitfalls.md`.
