# Рендер: `scripts/render.ps1`

Из `video/`: `.\scripts\render.ps1 -Studio <ключ> -Comp <композиция> -Out <имя>`. Ключ студии — из реестра `src/studios/studios.json` (`ads`, `features`, `youtube`; список — `node scripts/studios.mjs`); без `-Studio` студия определяется по id композиции (папка ролика или префикс id), иначе `ads`. Результат — `out/<Out>.mp4`, звук сведён под соцсети: −14 LUFS, пики не выше −1,5 dBTP.

| Флаг | Что делает |
|---|---|
| `-Draft` | черновик для проб: половинное разрешение, 30 к/с, сжатие сильнее; в 3–4 раза быстрее. Кадры для `-Frames` в черновике — секунда × 30 |
| `-Frames "A-B"` | только отрезок (фрагмент пользователю, проверка стыка). В чистовике YouTube (60 к/с) кадр = секунда × 60; секунды сцен печатает `yt-board` |
| `-Scale 2 -JpegQuality 95` | YouTube в 4K (3840×2160): постер и карты резкие при наезде |
| `-Notify` | тост Windows, когда рендер готов или упал (для долгих рендеров в фоне) |
| `-Concurrency N` | сколько кадров рендерить параллельно (по умолчанию 4, как в `remotion.config.ts`; больше — только по замеру `npx remotion benchmark`, не «на глаз») |
| `-Gl angle` | рендер WebGL через ANGLE — нужен, если в кадре «живой» арт (`DepthArt`, three.js) |
| `-MasterOnly` | только пересвести звук готового файла |

- **Лог** — `out/<Out>.render.log` (полный вывод Remotion и ffmpeg). При сбое скрипт выходит с кодом 1, показывает тост «упал» и не трогает прежний готовый файл. Смотреть лог, а не гадать.
- **Цвет:** YouTube-студии (`kind: youtube`) — BT.709, `yuv420p`, диапазон tv (метки в файле); реклама — как раньше; `yt-qa` по видео и `release.mjs` проверяют разрешение, к/с, формат пикселей, цвет и звук против `LIMITS.video` (`VIDEO_LIMITS` в `src/core/qa/limits.ts`, собирает `LIMITS` канала).
- **Долгий рендер** (8 мин YouTube в 4K60 — около 2 ч) — только после «да» на фрагменте; запускать в фоне (`run_in_background`) с `-Notify`; по окончании — проверка (`yt-qa.mjs <id>` по видео, затем `release.mjs <id>`) и сообщение пользователю.
- **Обложки YouTube** — `node scripts/yt-thumb.mjs <id>`: все варианты (`<id>-thumb`, `-thumb-b`, `-thumb-c`) в `out/<id>/thumbnail*.png` и лист читаемости `out/<id>/thumbs-sheet.jpg`. Один кадр вручную — `npx remotion still src/studios/<студия>/index.ts <композиция> <файл.png>` (точка входа обязательна: без неё `remotion.config.ts` подставит студию рекламы).
- **Реклама:** обе ориентации (`-Comp X` и `-Comp X16x9`), затем `.\scripts\qa.ps1 out\<имя>.mp4 -Cuts <кадры стыков>` (стыки launch30 — в паспорте `src/studios/README.md`).
- Полный рендер не удалять и не перезаписывать без слова пользователя.
