# «Глаза» и «уши» студии, права на чужой геймплей

Все команды — из `video/`. Скрипты: `scripts/eyes.mjs`, `scripts/rec.mjs`, `scripts/ears.py` (флаги — в их шапках).

## Свои записи — главный источник геймплея

Сейчас только Hearthstone. Пользователь пишет игры в OBS в `video/recordings/` (профиль и горячие клавиши — `video/recordings/README.md`) и во время игры жмёт «метку главы» сразу после удачного момента.

- `node scripts/rec.mjs` — новые записи → клипы `recordings/clips/<запись>-m<n>.mp4` вокруг каждой метки (−12…+3 с, со звуком игры; `--before/--after`); без меток — до 8 самых активных моментов (`-a<n>`, кандидаты). Обзор `recordings/clips/index.md` — полоски кадров: смотреть Read и выбирать по тексту диктора.
- В ролик: `node scripts/rec.mjs take <клип> --name <имя> [--trim 2-9] [--tight]` → `public/clips/<имя>.mp4` + паспорт («Геймплей: запись Манакоста»); `--tight` — срезать простой в начале и конце.
- Простой (ход соперника, ожидание, муллиган) — `node scripts/rec.mjs idle <запись | клип>`: по движению в кадре (auto-editor, музыка игры мешает искать по тишине) → `recordings/clips/<имя>.idle.md`: отрезки м:сс, итоги, метки в простое. Только подсказки, ничего не режет; порог и установка — `video/recordings/README.md`.
- Записи и клипы в git не идут, в git — только взятое в `public/clips`.
- Для другой игры — свой профиль OBS и свой README в `recordings/<игра>/` (заводит навык `studio-new-direction`); подпись и категория пока зашиты под Hearthstone.

## Чужой геймплей и референсы (`eyes.mjs`)

- `node scripts/eyes.mjs find "<запрос>" [--yt | --twitch] [--cc] [--days 30] [--n 10]` → `out/eyes/find-<запрос>.md` (+ `.json`): YouTube (поиск, лицензия каждого ролика, канал, просмотры, дата) и Twitch (самые просматриваемые клипы **категории Hearthstone** за `--days`: стример, кто нарезал клип, просмотры). Twitch по всей категории — с ключами `TWITCH_CLIENT_ID/SECRET` в `.env` (`--lang ru`); без ключей — по каналам (`--channels a,b`). Колонка «права»: CC BY — можно; иначе — нужно согласие автора.
- `node scripts/eyes.mjs search "<запрос>" [--cc]` — быстрый поиск на YouTube без лицензий.
- `node scripts/eyes.mjs look <url | файл> [--from 0 --to 300]` → `out/eyes/<имя>/report.md`: листы кадров с таймкодами, темп монтажа (склейки, средняя длина плана), активность по секундам, самые динамичные моменты полосками по 6 кадров через 0,2 с (`moment-*.jpg`, смотреть Read) — так разбирается, как устроен чужой переход или анимация.
- `node scripts/eyes.mjs scenes <url | файл>` → `out/eyes/<имя>/scenes.md`: планы по склейкам (PySceneDetect), ★ — план длиннее 8 с (кандидат на врезку).
- `node scripts/eyes.mjs cut <url> --from 40 --to 52 --name <имя>` → `public/clips/<имя>.mp4` (1080p) + паспорт `.json` (источник, автор, кто нарезал, лицензия, согласие). Берёт: CC BY; чужое с согласием автора — `--permission "написал в Telegram 03.10, ответил да"` (текст сохраняется в паспорт); своя запись — `--own`. Иначе — отказ.
- YouTube отвечает 403 на скачивание — устарел yt-dlp: `yt-dlp -U` (с согласия пользователя: качает новую версию с GitHub).

## Права

- **Указание автора — не разрешение.** Клипы Twitch и обычные ролики YouTube без согласия автора в ролик не берём (монетизируемый канал: Content ID, жалобы). Смотреть можно что угодно (разбор приёмов).
- Врезка без паспорта `<клип>.json` — `yt-qa` даёт ❌. Пробная врезка (`probe: true`, чужое «для примера») — не для выпуска: `release.mjs` даёт ❌.
- Во врезке: `credit` — из паспорта; вебкамеру и трекер стримера убрать `crop`.

## «Уши» (`ears.py`, окружение `.venv-vo`)

- `.venv-vo/Scripts/python.exe scripts/ears.py <id> [сцена…]` — голос по сценам: темп, паузы с местом в тексте, спектр, высота голоса, LRA; пометки «голос поднят — похоже на крик», «мало пауз», «монотонно».
- `--compare <дубль1> <дубль2>` — какой дубль спокойнее (один текст; спектр между разными текстами не сравнивать — шипящие его поднимают). Признак крика — высота голоса: «возбуждённое» вступление 219 Гц, спокойное 136 Гц.
- `--video <файл.mp4>` — готовое видео: громкость и звуки, которые громче обычного уровня на 6+ LU.
- `--metrics <файлы>` — цифры в JSON (для `vo-takes.mjs`).
