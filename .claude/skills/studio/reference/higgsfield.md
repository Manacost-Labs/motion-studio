# Higgsfield: живые фоны и генерация ассетов

Кредиты тратятся — перед любым запуском `node scripts/credits.mjs`, смета пользователю и «да». Сейчас Higgsfield используется рекламой HearthPulse (живые фоны, библиотека `public/lib`).

## Где в студии

- Стартовые кадры — композиции `plate-*` (`node scripts/plates.mjs` — вертикаль в `public/plates`, `plates.mjs h` — горизонталь в `public/plates-h`).
- Оживление — `.\scripts\gen-live.ps1` (Seedance 2.5, `omni_reference`, 1080p) → `public/live`, `public/live-h`; `-Resume "<имя>=<job_id>;…"` — только дождаться уже отправленных заданий.
- Музыка и звуки — `.\scripts\gen-audio.ps1`; библиотека — `node scripts/gen-library.mjs` (готовые файлы пропускаются, описание — `public/lib/manifest.json`).

## Особенности (выяснено 28.09.2026 на аккаунте пользователя)

- Каждому вызову CLI нужно рабочее пространство: `higgsfield workspace set <id>` (оно одно — Private).
- План Plus — **6 задач одновременно**; седьмая отправка падает с `rate_limit_reached`.
- Seedance 2.5 i2v (`--mode omni_reference --start-image`): 1080p — 48 кредитов (4 с) / 60 (5 с); на выходе 24 к/с; ~15–25 мин на клип. Стартовый кадр — лишь референс: модель может **перекомпоновать кадр** (выглядывающего снизу орка сделала крупным планом во весь кадр).
- Отказы `ip_detected` **возвращают кредиты**. Отклонены: ключевой арт Badlands (и размытый), вырезка орка в плашке 16:9. Прошли: арты Naxxramas, Frozen Throne, GvG, плашки на основе Rastakhan с вырезками персонажей. Ассеты библиотеки `public/lib` своих отказов не получают.
- `bytedance_image_upscale` падает на картинках с прозрачностью — наложить на ровный зелёный, увеличить, затем вырезать по доминированию канала (g − max(r, b)).
- `generate wait` принимает `--timeout`, а не `--wait-timeout` (тот только у `generate create --wait`).
- Звуки Seed Audio приходят с тишиной в начале и длинными хвостами — обрезать и нормализовать. Треки Sonilo могут затухать раньше (~27 с при запросе 30 с).
- Интерфейс сайта нейросетью не рисовать: видеомодели искажают текст и цифры. ИИ — только для фонов и персонажей.
