# Грабли (на каждой уже спотыкались)

## Движение и кадр

- **Медленное движение — только `transform`/`translate`/`scale`.** `left/top/width` Chrome округляет до пикселя у каждого элемента в свой момент — карты мелко дрожат (0,29 px шума → 0,02 после переноса постера в один слой с `transform`). Проверка — `cam-jitter.py`.
- Анимация только покадровая (`useCurrentFrame` + `interpolate`/`spring`; в YouTube — `ramp` из `src/core/time/ease.ts`). CSS-анимации, transition, GSAP и Framer Motion в Remotion не рендерятся.
- Точки камеры зажимать в кадр заранее (`planCamera(…, view)`), не каждый кадр — иначе у края упор и рывок.
- `Sfx` не класть внутрь слоя под `CameraMotionBlur` — слой рисуется копиями, звук задвоится.
- Фразу-привязку не зашивать в код сцены (было: «на вершине» во вступлении роняло рендер других роликов) — только поле конфига с запасным вариантом.
- **60 к/с:** время в «кадрах-30» через `useFrame()`, `Sequence`/звук × `useK()` (`src/core/time/fps.ts`). Иначе при 60 к/с деталь пойдёт вдвое быстрее.
- Ничего не пропадает резко: всё, что уходит, гаснет за 6–10 кадров.

## Файлы и кодировки

- **Кириллица:** не прогонять исходники через PowerShell `Get-/Set-Content` (Windows PowerShell 5.1 читает UTF-8 без BOM как cp1251 — комментарии превращаются в «РѕР±…»). Правки с `\n`, `\s`, обратными кавычками через `node -e` в bash ломаются экранированием — такие куски писать инструментами Edit/Write.
- Не запускать prettier по исходникам (`src/core`, `src/looks`, `src/games`, `src/brands`, студии): стиль — длинные строки (≈ `--print-width 200 --single-quote --no-bracket-spacing --object-wrap collapse`), иначе переформатируется весь файл. Если испортил — копии до правок в `~/.claude/file-history/<сессия>/`.
- Импорты только относительные; алиасы tsconfig `paths` webpack Remotion не читает.
- `npx remotion still|render` без точки входа берёт студию рекламы (`remotion.config.ts`) — всегда указывать `src/studios/<студия>/index.ts`.
- `prep-assets.ps1` не запускать — перезапишет `public/ui` закреплённой рекламы; кадры сайта режет `crop-ui.ps1`.

## Слои кода

- Импорт «вбок» или «вверх» (стиль → игра, сцена игры → бренд, ролик → `core` напрямую, студия → чужая игра) Stop-хук и pre-commit блокируют (`check-layers --strict`). Не обходить: перенести код в нужный слой или передать данные через `context` канала — правила `video/STUDIO.md`, «Правила импортов».
- `channel.ts` со всеми сценами скрипты собирают в Node (`scripts/lib/channel.mjs` → `yt-qa`, `yt-export`, `release`). Модуль, который при импорте трогает браузер (`fetch`, `document`, `loadFont`), их уронит — держать такие вызовы под `typeof document !== 'undefined'` (образец — `src/looks/compendium/theme.ts`).
- Кэш webpack Remotion узнаёт правку по дате файла: если вернуть `config.ts` с прежней датой (`cp -p`, ручной `touch`), сборка может взять старый модуль. Сдвигать дату хотя бы на секунду; при этом `yt-qa` сравнивает дату `config.ts` с обложками и описанием — более новый конфиг даст предупреждение о свежести.

## Проверки и эталоны

- `yt-golden.mjs --approve` — только после «да» пользователя; со списком сцен переснимаются только их кадры, без списка — весь эталон. Набор стыков (`--dir qa/golden-joints`) одобряется отдельно, с тем же `--dir`.
- Рефакторинг слоёв, канала или конфига: `yt-snap.mjs` до и после — хэши должны совпасть (иначе `diff` двух json покажет, что поменялось).
- Числа в `vo` распознавание пишет цифрами («Сорок» → —) — это норма, не ошибка произношения.

## Вкус и право

- Вкус — по направлению (`video/taste/`): то, что отвергнуто в одном направлении, не переносить в другое без вопроса, и наоборот.
- Цифры — только из источника (статья, скриншот сайта, `meta.json` с подписью источника).
- Чужой геймплей — только CC BY с автором или с согласием автора; `public/clips` без паспорта — для проб.
