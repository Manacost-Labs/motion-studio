# Голос: ElevenLabs, куски, дубли, нарезка

Сейчас голос есть только у YouTube Манакоста (диктор Alex Bell; вкус голоса — `video/taste/manacost-hs.md`). Скрипты голоса (`vo-*`, `tts.mjs`) сейчас ищут ролик в студии `manacost-youtube`; для нового направления их обобщают по реестру (этап B/C). Все команды — из `video/`.

## Перед записью

1. Текст `vo` готов и проверен: `node scripts/yt-qa.mjs <id> --no-video` — 0 ошибок (цифры словами, без латиницы, сокращения есть в словаре).
2. `node scripts/credits.mjs --need <знаков>` (сумму знаков печатает `vo-align.mjs --prepare`) — остаток; цену назвать пользователю (≈ 1 кредит за знак, ролик 8 мин ≈ 7–8 тыс.) и ждать «да».

## Через коннектор ElevenLabs (основной путь, без ключа)

- Вызов: `creative_generate_speech`, `model_id: eleven_v4`, `voice_id: TUQNWEvVPBLzMBSVDPUA` (Alex Bell, выбран пользователем), `generations_count: 1` — одна генерация, один раз платим; не повторять вызов «на всякий случай».
- Подача — живая, но спокойная: короткие фразы, паузы; `[warmly]` — тёплое начало, `[curious]` — интрига, `[pause]` — после точки. **Без `[excited]`** и серий «!» — диктор кричит.

Порядок:

1. Старые `out/<id>/vo-raw/chunk-*` и `chunks.json` перенести в `out/<id>/vo-raw/prev-<дата>/`.
2. `node scripts/vo-align.mjs <id> --prepare [--only hook,intro]` → `out/<id>/vo-raw/chunk-<n>.txt` (куски ~2000 знаков, между сценами `[long pause]`).
3. Текст каждого куска целиком — в `creative_generate_speech`.
4. `creative_get_flow_run_status` до `all_completed`, скачать `media[0].url` в `out/<id>/vo-raw/chunk-<n>.mp3` (`curl -s -o …`).
5. `node scripts/vo-align.mjs <id>` — режет куски по самым длинным паузам на сцены, темп +6 %, время каждого слова локально (`scripts/vo-words.py`, faster-whisper в `.venv-vo`), обработка голоса (`vo-fx.mjs`) → `public/vo/<id>/<сцена>.mp3` + `.json`. Печатает «распознано иначе» — передать пользователю «послушать».

Грабли коннектора: узел Scribe, подключённый к узлу речи, просто возвращает текст запроса без времени слов — не использовать, время слов даёт только локальный whisper. Whisper теряет текст на длинных кусках и с подсказкой из имён — распознавать по сценам (так делает `vo-align`). При нарезке с `afade` у ffmpeg `-ss` ставится перед `-i`.

## Дубли — только ключевые фразы

Начало, объявление №1, финал: после `vo-align.mjs <id> --prepare --only hook,deck-01,outro` каждый кусок записать 2–3 раза (каждый — отдельный вызов, `generations_count: 1`) и сохранить как `chunk-<n>.take-1.mp3`, `chunk-<n>.take-2.mp3`…; `node scripts/vo-takes.mjs <id>` мерит дубли (высота голоса против обычной для ролика, слова, услышанные непохоже, паузы), отбрасывает «поднятые» (крик), лучший копирует в `chunk-<n>.mp3` (`--dry` — только отчёт `out/<id>/vo-raw/takes-report.md`); дальше `vo-align.mjs <id>`. Весь ролик в нескольких дублях не писать — кредиты.

## Через API (запасной путь)

`node scripts/tts.mjs <id>` — смета (ничего не тратит); `--go [сцена…]` — записать изменившиеся сцены; `--force` — даже если текст не менялся. Ключ `ELEVENLABS_API_KEY` — только в `video/.env`, его кладёт пользователь; значение не выводить.

## После записи

- `.venv-vo/Scripts/python.exe scripts/ears.py <id>` — нет «голос поднят — похоже на крик», «мало пауз», «монотонно».
- `yt-qa` снова — теперь и произношение («термин звучит иначе»). Читает неверно → слово в словарь и перезаписать сцену (`--only <сцена>`); распознавание ошиблось — ничего.
- Паузы внутри фразы: `ffmpeg -hide_banner -i public/vo/<id>/<сцена>.mp3 -af silencedetect=n=-40dB:d=0.25 -f null -`.
- Текст сцены правили после записи → привязки по доле текста, `yt-qa` предупредит: перезаписать эту сцену.

## Обработка и словарь

- `node scripts/vo-fx.mjs <id> [--preset broadcast|warm|off]`: сухие записи `out/<id>/vo-raw/dry/` → `public/vo/<id>/`; пресет по умолчанию — `voice.fx` в конфиге или `broadcast`. `vo-align` и `tts` вызывают сами.
- Словари произношения склеиваются сами (позже — главнее): термины игры — `src/games/<игра>/data/pronounce.json` (у Hearthstone — `src/games/hearthstone/data/pronounce.json`: ДК, ДХ, ОТК, имена с апострофом) → бренд канала — `src/studios/<студия>/pronounce.json` (у Манакоста пока пуст) → `pronounce` конфига — только слова этого ролика. Склеивают `scripts/vo-lib.mjs` (озвучка, смета; игра — по полю `game` студии в `studios.json`) и `channel.qa` (yt-qa). На экране остаётся написание из `vo`.
- Субтитров в кадре с голосом нет — только `.srt` из `yt-export.mjs`.
