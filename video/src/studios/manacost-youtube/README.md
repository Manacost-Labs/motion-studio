# Студия YouTube-роликов Манакоста — «Компендиум» (16:9, под озвучку)

Горизонтальные ролики по материалам hs-manacost.ru: подборки колод, гайды на колоду, обзоры. Оформление — дизайн-система HS-Arena (arena.hs-manacost.ru, файлы design.md и assets.md в репозитории Manacost-Labs/HeartPulse): пергамент, красное тавернное сукно, дерево, золото только в мелочах. Ассеты сайта лежат в `public/brand/arena`. Стиль — `src/looks/compendium`, сцены и данные игры — `src/games/hearthstone`, бренд — `src/brands/manacost`; студия собирает их в ролики.

## Паспорт студии

Ключ `youtube` в `src/studios/studios.json` (игра `hearthstone`, стиль `compendium`, бренд `manacost`, id роликов `yt-…`, эталоны — `golden`), запуск — `npm run studio:youtube`. В папке студии только:

| Файл | Что |
|---|---|
| `channel.ts` | канал: стиль, бренд, игра, все виды сцен (`defineChannel`), ctx сцен, тип конфига `YtConfig`, каркас ролика по статье (`articleDeck`, `divider`, `manacostOutro`, `YT_BASE`), пороги `LIMITS`, проверки канала `qa` |
| `videos.ts` | список роликов `VIDEOS` — строка на ролик (добавляет `scripts/yt-new.mjs`) |
| `Root.tsx`, `index.ts` | регистрация: ролики из `videos.ts` (`voicedCompositions`, `src/core/video/compositions.tsx`), обложка (`src/games/hearthstone/scenes/thumb.tsx`), демо, стенд постеров, витрины |
| `pronounce.json` | словарь бренда канала (термины игры — `src/games/hearthstone/data/pronounce.json`) |
| `judge.ts` | смысловой судья (`scripts/judge.mjs`) и его пороги `JUDGE` |
| `motion-showcase/` | демо всех сцен (`demo.ts` → `yt-template-demo`), витрина движения (`Showcase.tsx`), «живой» арт (`DepthLab.tsx`) |
| `yt-<тема>/` | ролик: `config.ts` (импортирует только `../channel`), `article.json`, `meta.json` |
| `template/` | только карта «куда переехало» для старых ссылок |

Остальное — в общих слоях: движок под голос, звук, проверки — `src/core`; стиль — `src/looks/compendium`; сцены и данные Hearthstone, образец статьи и стенд постеров — `src/games/hearthstone` (`GAME.md`); имя, ссылки, финал, голос и музыка канала — `src/brands/manacost/channel.ts`. Правила импортов — `scripts/check-layers.mjs`.

Ролик делается «как будто есть озвучка»: весь смысл идёт в тексте диктора `vo`, на экране — заголовки, тезисы и карты, которые оживают в момент, когда диктор до них доходит. Пока голоса нет, длина сцен считается по тексту (15 знаков/с) и показываются субтитры. Когда запись появится, ничего переделывать не нужно.

Живой пример всех сцен — композиция **`yt-template-demo`** (гайд на Дракон Воина, `motion-showcase/demo.ts`).

Этот файл — справочник движка: сцены, поля, детали, звук. **Порядок работы над роликом** (заготовка, заполнение, голос, проверки, рендер, выпуск) — только в навыке `manacost-youtube` (`.claude/skills/manacost-youtube/SKILL.md`), общие инструменты — в навыке `studio`. Статусы приёмов («проба», «одобрено», «отвергнуто») — `video/taste/manacost-hs.md`. Пороги проверок — `LIMITS` в `channel.ts` (собирает общие `src/core/qa/limits.ts`, колоды и обложки `src/games/hearthstone/data/audit.ts` и свои; здесь — имя константы и её значение).

## Сцены (`kind`)

Ролик — список сцен в любом порядке. У каждой: `id`, `vo` (текст диктора), по желанию `chapter` (глава в описании YouTube) и `mural` (полупрозрачный персонаж-вырезка из public).

| kind | Что на экране | Для чего |
|---|---|---|
| `hook` | Сильное начало до вступления: красное сукно, слева крупное золотое число со счётчиком (`value`, `label`, на фразе `at`) и удар барабана, справа веер карт (`cards`), внизу добивка с гербом (`punch`: «и это всего лишь 15-е место»). Своей главы в описании нет — входит во «Вступление» с 0:00 | Первые 4–6 с: самый яркий факт ролика, одна фраза голосом |
| `divider` | Разделитель блоков без голоса (~2,6 с, музыка без приглушения): сукно, «Дальше», крупное «Топ-10» из-под маски, ряд медалей мест блока (`block: [10, 6]`), удар барабана. Глава — у следующей колоды | Между частями длинного топа (у топ-3 своя заставка места) |
| `intro` | Шапка из сукна с логотипом, крупный заголовок чернилами, подпись, строка гербов классов (`classes`), полупрозрачный паладин; `tease` — постеры топа веером под размытием с «?» (крючок) | Начало любого ролика; 8–12 с |
| `deck` | Шапка: герб класса, класс · режим, название, место в топе (`rank`). Слева «Главное» — тезисы «заголовок + пояснение» делят всю высоту колонки (тот, о котором говорит диктор, подчёркнут чернилами по строкам); внизу «Матч-апы» (`vs`) — видны с начала сцены приглушёнными, на своей фразе плашка загорается и получает вердикт, — и строка «пыль · код колоды». Справа постер колоды из api.blizzcore.ru: названная карта — наезд камеры, карта приподнимается и светлеет; пауза без карт — медленный обход постера; названная карта не из колоды — карточка «упомянута» слева. Места 1–3 открываются заставкой места. Без постера — список колоды как на сайте | Подборки и обзор колоды в гайде |
| `cards` | Ряд из 1–4 крупных карт с подписями, появляются под голос; тезисы слева по желанию | Ключевые карты, комбо, техи |
| `mulligan` | Колонки «оставлять / по ситуации / менять» цветными чернилами, карты под голос | Гайды |
| `matchups` | Ведомость: герб класса · название и пояснение · итог (`good`/`even`/`bad`) или процент побед с полосой | Гайды, обзоры меты. Процент — только реальные цифры |
| `points` | Крупные тезисы, справа карта, портрет героя в деревянной раме или картинка | Советы, план на игру, выводы |
| `image` | Скриншот в деревянной раме с наездом, подпись и источник | Скриншоты из статьи, игры, Reddit (всегда указывать автора) |
| `outro` | Прощание и ссылки слева, справа рамки под конечную заставку YouTube; держится 5 с. С `recap: {to, kicker, title}` финал открывается итоговой таблицей всех колод по местам (3 колонки × 5, обратный отсчёт, №1 в золотой раме; данные — из сцен колод), на фразе `to` страница перелистывается на заставку, шапка меняет надписи (`HeaderBand next`) | Конец любого ролика |

Привязка «под голос»: `at` — фраза из `vo` (без учёта регистра). Нет фразы — рендер остановится и назовёт её. Без `at` элементы распределяются по тексту равномерно.

## Ролик по шаблону

Порядок работы — навык `manacost-youtube`. Здесь — что где лежит:

- **Конфиг** — `src/studios/manacost-youtube/yt-<тема>/config.ts` (готовый образец — `yt-legend-decks-sep26/config.ts`, все сцены — `motion-showcase/demo.ts`). Заготовку подборки по статье делает `scripts/yt-new.mjs`; каркас (колоды из статьи, разделители, финал, голос, музыка) — `channel.ts`.
- **Регистрация** — строка в `videos.ts` (`Root.tsx` регистрирует список) → композиции `yt-<тема>`, обложка `yt-<тема>-thumb` (и `-thumb-b`, `-thumb-c` при `thumbs`).
- **Пороги полей** (`LIMITS`, `channel.ts`): заголовок тезиса `text` — `LIMITS.pointText` = 28 знаков (длиннее — две строки, заметка), пояснение `detail` — `LIMITS.pointDetail` = 52 (длиннее — предупреждение), тезисов на колоду — `LIMITS.pointsMax` = 3, обводок `ink` — `LIMITS.inkMax` = 3, строка обложки — `LIMITS.thumbLine` = 14.
- **Описание и поиск** — `seo: {lead, hashtags, tags, titles}` (тип `YtSeo` в `channel.ts`): лид — первая строка описания, не повтор названия; хэштеги — до трёх; теги → `tags.txt`, варианты названия → `titles.txt` (их пишет `yt-export.mjs`).
- **Варианты обложки** — `thumbs: [{…}, {…}]` поверх `thumb` (другой `hook`, `badge` или карты), всего до `LIMITS.thumbVariants` = 3 для «Тест и сравнение» YouTube; лист читаемости — `scripts/yt-thumb.mjs`.
- **Карты** — `cards: [{id, at}]`; недостающие рендеры — `scripts/hs-assets.mjs`. Статистика меты — `meta.json` (`scripts/meta-stats.mjs`). Установлены и готовы к новым приёмам `@remotion/noise` (живая неровная подвижка) и `@remotion/three` (3D, например переворот карты).

## Новая сцена

Сцена без игры (стиль) — файл в `src/looks/compendium/scenes/`, сцена Hearthstone — в `src/games/hearthstone/scenes/`: тип сегмента (`types.ts` рядом), компонент и его правила — `defineScene({kind, Component, lead, min, tail, chapter, subtitleZone, audit, assets})` (`src/core/video/registry.ts`; умолчания пауз — `src/core/voice/calc.ts`); строка в `index.ts` папки сцен и в `scenes` канала (`channel.ts`). Бренд, гербы и строки итоговой таблицы сцена получает через `ctx` канала (`CompendiumCtx`, `src/looks/compendium/types.ts`; собирает `channel.ts` → `context`). Тип конфига ролика выводится из канала (`YtConfig = ConfigOf<typeof channel>`): сцена с чужим `kind` не проходит tsc. Проверки данных сцены (yt-qa) — `audit` (у колоды — `src/games/hearthstone/data/audit.ts`), резкие смены кадра — `jumps`, карта темпа — `pace`, сцена без голоса — `silent`; проверки канала (обложка, гербы, словари) — `qa` в `channel.ts` (`src/core/qa/audit.ts`). Детали стиля — `src/looks/compendium/parts/` (`Page`, `HeaderBand`, `WoodRule`, `MainPoints`, `Mural`, `Words`, `Subtitles`, `InkCircle`, `WaxSeal`, `RankReveal`, `RecapBoard`, `Vignette`) и `motion.tsx` (`SceneBody`, `PageLayer`); детали Hearthstone — `src/games/hearthstone/scenes/parts/` (`DeckPoster`, `VersusBlock`, `OffDeckCard`, `CardRow`, `HeroPortrait`, `DeckList`, `ComboPanel`, `ClipPanel`, `DeckFooter`, `crestFor`, `recapRow`; план камеры `planCamera` — `src/games/hearthstone/data/camera.ts`); общее — `src/core` (`useFitSize` в `layout/fit.tsx`: кегль по ширине через `@remotion/layout-utils` — для любого крупного текста, длина которого заранее неизвестна; `Sfx`, `Grain`, `DepthArt` в `fx/DepthArt.tsx`: «живой» арт — параллакс по карте глубины из `scripts/depth.py`, рендер с `render.ps1 -Gl angle`; статус — `video/taste/manacost-hs.md`).

Звук ролика (движок `src/core/video/VoicedVideo.tsx`): музыка приглушается под словами диктора (по времени символов из `<сцена>.json`) и мягко поднимается в паузах от 1 с — внутри сцены наполовину, между сценами до полной; `config.ambience` — тихие бесшовные петли под всем роликом (`lib/amb/tavern-crowd.wav`, `lib/amb/tavern-fire.wav`; статус — `video/taste/manacost-hs.md`).

## Озвучка (ElevenLabs, модель eleven_v4)

- **Голос и произношение** — в конфиге: `voice.id` (сейчас Alex Bell, `TUQNWEvVPBLzMBSVDPUA`); как читать аббревиатуры
  и имена (ОТК → «о-тэ-ка») — словари игры `src/games/hearthstone/data/pronounce.json` (термины) и студии `pronounce.json` (бренд) подмешиваются сами, `pronounce` ролика — для его особых слов; на экране остаётся написание из `vo`. Аудиотеги v4 в `vo` (`[pause]`, `[warmly]`, `[curious]`) диктор исполняет,
  на экран они не попадают. `[excited]` не ставить — Alex Bell с ним кричит (02.10); живость — словами и паузами. Латиницу и цифры в `vo` не писать.
- **Запись** — через коннектор ElevenLabs (`vo-align.mjs --prepare` → куски → `vo-align.mjs`) или через API (`tts.mjs`, ключ в `video/.env`). Порядок, дубли, траты — `.claude/skills/studio/reference/voice.md`. Результат одинаковый: `public/vo/<id>/<сцена>.mp3` + `.json` (время каждого символа).
- `calcYt` (`calcVoiced`, `src/core/voice/calc.ts`) берёт длину сцены из записи, а время слов — из `.json`: карты, тезисы, матч-апы и субтитры встают точно на слово.
  Если текст сцены правили после записи — в консоли предупреждение, привязки по доле текста; перезапишите сцену.
- С голосом субтитров в кадре нет (`subtitles: 'auto'`); для YouTube — `yt-export.mjs` → `subtitles.srt` (две строки ~42 знака).
- Без голоса длина сцен оценивается по `CPS` в `src/core/voice/timing.ts`.

## 60 кадров, врезки, обработка голоса, автопроверка (01.10)

- **60 к/с:** `fps: 60` в конфиге. Все длительности в сценах и деталях (стиль, игра, core) — в «кадрах-30» (`src/core/time/fps.ts`): детали берут время через `useFrame()`,
  `Sequence` и звук умножаются на `useK()`. Новые детали пишите так же, иначе при 60 к/с они пойдут вдвое быстрее.
- **Врезки в сцене колоды** (`DeckSeg.inserts`, `src/games/hearthstone/scenes/parts/inserts.tsx`) — на месте постера, пока звучит фраза `at … to`:
  `combo` — карты комбо (блёклые, загораются на своих фразах) и итоговые числа со счётчиком (числа — только из источника);
  `clip` — видео из `public/clips` с кадрированием `crop`, обязательной подписью автора `credit` и паспортом `<клип>.json` рядом (`eyes.mjs cut`, `rec.mjs take`). `probe: true` — пробная врезка (чужой геймплей «для примера»): по данным предупреждение, по видео и в `release.mjs` — ❌, для выпуска заменить.
  Чужой геймплей — только по лицензии (YouTube-фильтр Creative Commons, CC BY) и с автором в кадре и в описании; лучше — своя запись.
- **Обработка голоса** (`scripts/vo-fx.mjs`): сухие записи `out/<id>/vo-raw/dry/` → `public/vo/<id>/`; пресеты `broadcast`
  (по умолчанию), `warm`, `off` — `voice.fx` в конфиге. `vo-align.mjs` и `tts.mjs` вызывают обработку сами.
- **Автопроверка** `node scripts/yt-qa.mjs <id> [--video файл] [--no-video]` → `out/<id>/qa-report.md`: данные сцен (`src/core/qa/audit.ts`,
  проверки канала и сцен, пороги `LIMITS`), файлы, произношение, громкость, цвет и рывки готового видео. Все проверки и порядок —
  `.claude/skills/studio/reference/quality.md`.
