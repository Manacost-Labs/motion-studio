# Шаблон YouTube-роликов Манакоста — «Компендиум» (16:9, под озвучку)

Горизонтальные ролики по материалам hs-manacost.ru: подборки колод, гайды на колоду, обзоры. Оформление — дизайн-система HS-Arena (arena.hs-manacost.ru, `design.md` / `assets.md` в репозитории Manacost-Labs/HeartPulse): пергамент, красное тавернное сукно, дерево, золото только в мелочах. Ассеты сайта лежат в `public/brand/arena`.

Ролик делается «как будто есть озвучка»: весь смысл идёт в тексте диктора `vo`, на экране — заголовки, тезисы и карты, которые оживают в момент, когда диктор до них доходит. Пока голоса нет, длина сцен считается по тексту (15 знаков/с) и показываются субтитры. Когда запись появится, ничего переделывать не нужно.

Живой пример всех сцен — композиция **`yt-template-demo`** (гайд на Дракон Воина, `demo.ts`).

## Сцены (`kind`)

Ролик — список сцен в любом порядке. У каждой: `id`, `vo` (текст диктора), по желанию `chapter` (глава в описании YouTube) и `mural` (полупрозрачный персонаж-вырезка из public).

| kind | Что на экране | Для чего |
|---|---|---|
| `intro` | Шапка из сукна с логотипом, крупный заголовок чернилами, подпись, строка гербов классов (`classes`), полупрозрачный паладин; `tease` — постеры топа веером под размытием с «?» (крючок) | Начало любого ролика; 8–12 с |
| `deck` | Шапка: герб класса, класс · режим, название, место в топе (`rank`). Слева «Главное» — тезисы «заголовок + пояснение», под ними «Матч-апы» (`vs`). Справа постер колоды из api.blizzcore.ru: названная карта — наезд камеры, карта приподнимается и светлеет; пауза без карт — медленный обход постера; названная карта не из колоды — карточка «упомянута» слева. Места 1–3 открываются заставкой места. Без постера — список колоды как на сайте | Подборки и обзор колоды в гайде |
| `cards` | Ряд из 1–4 крупных карт с подписями, появляются под голос; тезисы слева по желанию | Ключевые карты, комбо, техи |
| `mulligan` | Колонки «оставлять / по ситуации / менять» цветными чернилами, карты под голос | Гайды |
| `matchups` | Ведомость: герб класса · название и пояснение · итог (`good`/`even`/`bad`) или процент побед с полосой | Гайды, обзоры меты. Процент — только реальные цифры |
| `points` | Крупные тезисы, справа карта, портрет героя в деревянной раме или картинка | Советы, план на игру, выводы |
| `image` | Скриншот в деревянной раме с наездом, подпись и источник | Скриншоты из статьи, игры, Reddit (всегда указывать автора) |
| `outro` | Прощание и ссылки слева, справа рамки под конечную заставку YouTube; держится 5 с | Конец любого ролика |

Привязка «под голос»: `at` — фраза из `vo` (без учёта регистра). Нет фразы — рендер остановится и назовёт её. Без `at` элементы распределяются по тексту равномерно.

## Дизайн (`theme.ts`, `parts/`)

- **Материалы:** пергамент (`arena-parchment.jpg`) — фон всех сцен, красное сукно (`arena-rail-red.jpg`) — шапка 150 px и плашка субтитров, дерево (`main-page-rail-border.png`) — рамы и планки, золотая рама (`deck-border.png`) — места под конечную заставку. Гербы классов — `class_icon/*.png`.
- **Шрифты:** заголовки — HSDisplay (Belwe), текст — Inter, как на сайте. Номера тезисов и место — Belwe красными/золотыми чернилами.
- **Тезисы:** все проявляются в начале сцены приглушёнными, тот, о котором говорит диктор, — в полную силу; подсветка не чаще раза в 3 с.
- **Матч-апы** (`DeckSeg.vs`): только то, что сказано в источнике — герб, подпись, «сильнее/слабее», загораются под голос.
- **Раскладка сцены колоды:** левая колонка одной ширины во всех сценах; без субтитров в кадре постер занимает и нижнюю полосу.
- **Топ-3:** заставка места (`RankReveal`) — сукно во весь кадр с золотой цифрой (у №1 — «Лидер меты») и ударом барабана, уходит вверх и становится шапкой. Перед названием колоды в `vo` — `[pause]`.
- **Постер колоды:** `scripts/deck-posters.mjs` скачивает постеры (стиль `parchment`) и порядок карт на них. Камера (`parts/posterCam.tsx`) наезжает на названную карту (26 кадров, зум 2,4), карта приподнимается на 10%, светлеет, получает тёплый свет, остальная колода чуть притухает; через ~3 с — отъезд или сразу переезд к следующей карте. Движение камеры — с размытием в движении. Если карты не звучат дольше ~7 с, камера медленно обходит постер (зум 1,4) и возвращается на общий план. Карты, которых нет в колоде, камера пропускает — их показывает карточка «упомянута» (`OffDeckCard`).
- **Резкость постера:** постер с сервиса всего 1920 px в ширину (карта ≈236 px), и API не отдаёт его крупнее. Поэтому поверх каждой карты постера лежит её рендер HearthstoneJSON 512 px, а ролик рендерится в 4K (`-Scale 2`): на общем плане постер показан примерно 1:1, при наезде карта остаётся резкой. Размытие в движении — `CameraMotionBlur` (копии кадра наложением, обычный DOM). Точки камеры `planCamera` зажимает в границы кадра заранее (параметр `view`): если зажимать каждый кадр, у края постера камера стоит на упоре и срывается рывком.
- **Раскладка карт на постере:** `node scripts/poster-fit.mjs <папка> [место]` сверяет каждую ячейку постера со всеми картами колоды и записывает в `poster` точный порядок и `rects` (прямоугольник рендера каждой карты). Порядок нельзя угадывать по стоимости: связанные карты (например, молот и облик Мурадина) сервис ставит сразу за владельцем. Проверка наложением «разностью»: `npx remotion still yt-poster-calib out.png --props='{"rank":9}'` — совпадение почти чёрное.
- **Сетка по умолчанию** (`poster.ts`, если нет `rects`): 8 колонок (19–24 карты) и 6 колонок (до 18), поправки для существ, заклинаний и легендарок.
- **Склейки:** растворение через чистый пергамент и тихий свист. Поверх — лёгкое зерно и тёплая виньетка.
- **Без «нейросетевого почерка»:** никаких свечений, искр, неона, покачиваний и тряски; тексты — из-под маски, движения — мягкие кривые.

## Новый ролик

1. **Данные.** Подборка по статье: `node scripts/fetch-article.mjs <url> yt-<тема>` → `src/studios/manacost-youtube/yt-<тема>/article.json`. Затем постеры: `node scripts/deck-posters.mjs yt-<тема>` (сам запускает `poster-fit.mjs`, ~1 мин на колоду). Для гайда хватит кода колоды.
2. **Конфиг** `src/studios/manacost-youtube/yt-<тема>/config.ts` — по образцу `yt-legend-decks-sep26/config.ts` (подборка) или `template/demo.ts` (гайд):
   - `vo` — пересказ своими словами, разговорно, числа словами, без ссылок и латиницы, которую диктор не прочтёт;
   - тезисы — `{text: заголовок до ~28 знаков, detail: пояснение до ~45, at}`; цифры — только из источника;
   - карты под голос — `cards: [{id, at}]`; рендеры докачать `node scripts/hs-assets.mjs <id…>`.
3. **Регистрация** в `src/studios/manacost-youtube/Root.tsx`: `<Folder name="yt-<тема>"><YtCompositions config={…} /></Folder>` → композиции `yt-<тема>` и `yt-<тема>-thumb`.
4. **Проверка:** `node scripts/yt-export.mjs yt-<тема>` печатает хронометраж → `node scripts/stills.mjs yt-<тема> <кадры…>`.
5. **Голос** — раздел «Озвучка» ниже. **Рендер (4K):** `.\scripts\render.ps1 -Studio youtube -Comp yt-<тема> -Out "yt-<тема>\video" -Scale 2 -JpegQuality 95` (~1 ч на 8 минут ролика), обложка `npx remotion still src/studios/manacost-youtube/index.ts yt-<тема>-thumb out/yt-<тема>/thumbnail.png`, проверка `.\scripts\qa.ps1 out\yt-<тема>\video.mp4 -Cuts <кадры стыков>`.
6. **К загрузке:** `node scripts/yt-export.mjs yt-<тема>` → `out/yt-<тема>/description.txt` (главы, коды колод, ссылки), `subtitles.srt`, `script.md` (сценарий для диктора).

## Новая сцена

Файл в `scenes/`, строка в `Scene` (`scenes/index.tsx`), тип в `types.ts`. Детали — в `parts/`: `Page`, `HeaderBand`, `WoodRule`, `MainPoints`, `Mural`, `DeckFooter`, `DeckPoster` + `planCamera`, `VersusBlock`, `OffDeckCard`, `RankReveal`, `CardRow`, `HeroPortrait`, `DeckList`, `Words`, `Subtitles`, `Grain`, `Vignette`, `Sfx`.

## Озвучка (ElevenLabs, модель eleven_v4)

- **Голос и произношение** — в конфиге: `voice.id` (сейчас Alex Bell, `TUQNWEvVPBLzMBSVDPUA`), `pronounce` — как читать аббревиатуры
  и имена (ОТК → «о-тэ-ка»), на экране остаётся написание из `vo`. Аудиотеги v4 в `vo` (`[pause]`, `[excited]`) диктор исполняет,
  на экран они не попадают. Латиницу и цифры в `vo` не писать.
- **Через коннектор ElevenLabs** (без ключа):
  1. `node scripts/vo-align.mjs <id> --prepare` → `out/<id>/vo-raw/chunk-<n>.txt` (куски по ~2000 знаков, между сценами `[long pause]`);
  2. каждый кусок — генерация речи моделью `eleven_v4` тем же голосом, результат → `out/<id>/vo-raw/chunk-<n>.mp3`;
  3. `node scripts/vo-align.mjs <id>` — режет по паузам на сцены, распознаёт время слов локально (`scripts/vo-words.py`,
     faster-whisper; один раз: `python -m venv .venv-vo && .venv-vo/Scripts/python -m pip install faster-whisper`) и пишет
     `public/vo/<id>/<сцена>.mp3` + `.json`. Печатает слова, распознанные иначе, — их стоит послушать.
- **Через API** (ключ в `video/.env`): `node scripts/tts.mjs <id>` — смета, `--go` — запись изменившихся сцен.
- `calcYt` берёт длину сцены из записи, а время слов — из `.json`: карты, тезисы, матч-апы и субтитры встают точно на слово.
  Если текст сцены правили после записи — в консоли предупреждение, привязки по доле текста; перезапишите сцену.
- С голосом субтитров в кадре нет (`subtitles: 'auto'`); для YouTube — `yt-export.mjs` → `subtitles.srt` (две строки ~42 знака).
- Без голоса длина сцен оценивается по `CPS` в `timing.ts`.
