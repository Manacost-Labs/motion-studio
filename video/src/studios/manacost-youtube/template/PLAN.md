# План доработки YouTube-шаблона (по разбору ролика «15 колод для Легенды», 29.09.2026)

Порядок важен: озвучка идёт первой — от реальной речи зависят все тайминги (карты, тезисы, субтитры, длина сцен).
Отметки: ☐ — не начато, ◐ — частично, ☑ — готово, ❓ — нужно решение.

## Этап 0. Озвучка ElevenLabs v4 — фундамент

- ☑ **0.1 Конвейер.** Два пути, результат одинаковый — `public/vo/<id>/<сегмент>.mp3` + `.json` (время каждого символа
  текста на экране):
  - **через коннектор ElevenLabs** (без ключа; так записан ролик 29.09): `node scripts/vo-align.mjs <id> --prepare` → куски
    по ~2000 знаков, между сценами `[long pause]` → каждый кусок озвучивается моделью v4 → `out/<id>/vo-raw/chunk-<n>.mp3` →
    `node scripts/vo-align.mjs <id>` режет куски по паузам на сцены и локально распознаёт время слов
    (`scripts/vo-words.py`, faster-whisper в `video/.venv-vo`). Коннектор списывает ~1 кредит за знак (≈ $1,5 за ролик);
  - **через API с ключом** в `video/.env`: `node scripts/tts.mjs <id>` (смета) → `--go` (эндпоинт with-timestamps, кэш по хэшу,
    контекст соседних сцен). По тарифу API ≈ $0,16 за ролик.
- ☑ **0.2 Голос.** Выбран Alex Bell — News Broadcasting (`TUQNWEvVPBLzMBSVDPUA`), модель `eleven_v4`; пробы четырёх
  голосов — `out/yt-legend-decks-sep26/voice-samples/v4/`.
- ☑ **0.3 Тайминги по реальной речи.** `calcYt` читает `.json`: карты, тезисы, матч-апы и субтитры встают по времени слова.
  Если текст сцены изменили после записи — предупреждение и возврат к доле текста. Аудиотеги вырезаются (`stripTags`).
- ☑ **0.4 Текст под голос.** `pronounce` в конфиге (ОТК, ДК, МАТРИАРХ, ШРУ, Граб'Зи), ник чемпиона латиницей убран из текста,
  `[pause]` перед названием колоды в топ-3.
- ☑ **0.5 Сведение.** Голос поверх музыки ×0,45×0,3 (≈ на 13 дБ ниже речи), разброс громкости микса 2,5 LU, мастер −14 LUFS.

## Этап 1. Удержание зрителя

- ☑ **1.1 Вступление 26 с → 11 с.** Первая фраза — крючок, №1 не называем (решение 29.09): «Воин на вершине, но какой именно —
  узнаем в самом конце». Три постера топ-3 веером под размытием, на переднем — «?» (`IntroSeg.tease`).
- ☑ **1.2 Нет простоя колоды.** Если карта не звучит дольше ~7 с, камера медленно обходит постер (две точки, зум 1,4,
  без размытия) и к следующей названной карте возвращается на общий план (`planCamera`). В текст колод №7, №6, №5, №4
  добавлены карты из их списков (легендарки, Сглаз, Костоправ).
- ◐ **1.3 Топ-3 — событие.** Заставка места (`RankReveal`): сукно во весь кадр, золотая цифра, «Лидер меты» у №1, удар барабана,
  пауза в голосе; сукно уходит вверх и становится шапкой сцены. Не сделано: золотая рама постера у №1.

## Этап 2. Кадр

- ☑ **2.1 Левый нижний угол.** Блок «Матч-апы» (`DeckSeg.vs`, только то, что сказано в статье): герб, подпись, «сильнее/слабее»
  под голос. Карта, которую назвали, но её нет в колоде, — карточкой «упомянута» на ~4 с (`OffDeckCard`).
- ☑ **2.2 Ровная раскладка.** Левая колонка одной ширины во всех сценах. Без субтитров в кадре колоде отдана нижняя полоса:
  постеры в 8 и в 6 колонок теперь почти одной ширины (963 и ~930 px).
- ☑ **2.3 Тезисы.** Не чаще раза в 3 с (`POINT_GAP`).

## Этап 3. Субтитры

- ☑ **3.1 Разбивка.** Две строки ~42 знака (до 50), без висящих предлогов, короткие куски склеиваются; по реальной речи.
  В ролике 29.09: 126 фраз, минимум 1,4 с на экране.
- ☑ **3.2** С голосом субтитров в кадре нет (`subtitles: 'auto'`), для YouTube — `out/<id>/subtitles.srt` (решение 29.09).

## Этап 4. Звук

- ☑ **4.2 Звук мест.** Перелистывание страницы на каждой колоде, удар барабана на заставках топ-3.
