# План доработки YouTube-шаблона (по разбору ролика «15 колод для Легенды», 29.09.2026)

Порядок важен: озвучка идёт первой — от реальной речи зависят все тайминги (карты, тезисы, субтитры, длина сцен).
Отметки: ☐ — не начато, ◐ — в работе, ☑ — готово, ❓ — нужно решение.

## Этап 0. Озвучка ElevenLabs v4 — фундамент

- ◐ **0.1 Конвейер.** Ключ в `video/.env` (в git не попадает). `scripts/tts.mjs`: смета без трат → `--go` пишет
  `public/vo/<id>/<сегмент>.mp3` + `.json` с посимвольными метками времени (эндпоинт with-timestamps). Кэш по хэшу
  текста и настроек — неизменённые сегменты не перезаписываются и не оплачиваются. Соседние сегменты передаются
  как контекст (previous/next_text), чтобы интонация не рвалась на стыках. Цена: ~7 000 знаков ≈ $0,16 за полный дубль.
- ❓ **0.2 Голос.** Пробы 4 кандидатов на нашем тексте (вступление + №1): `--samples intro,deck-01 --voices …`.
  Выбранный голос — в конфиг (`voice.id`), подобрать `speed` (ориентир 1.0–1.08) и `stability`.
- ☐ **0.3 Тайминги по реальной речи.** `calcYt` читает `.json`: привязки `at` (карты, тезисы) — по времени слова,
  а не по доле символов; субтитры — по меткам начала/конца фраз. Аудиотеги v4 (`[pause]`, `[excited]`) вырезаются
  из текста на экране (`stripTags` в `timing.ts`).
- ☐ **0.4 Текст под голос.** Словарь `pronounce` в конфиге: ОТК, ДК, ШРУ, OTHxhh (латиница!), МАТРИАРХ, Зи/Граб Шаман,
  Кхелос, Хлад ван Пир. Аудиотеги — точечно: пауза перед объявлением места, `[excited]` на топ-3.
- ☐ **0.5 Сведение.** Голос −16 LUFS в миксе, музыка под голосом ×0,3 (уже есть) — проверить на слух и по графику.

## Этап 1. Удержание зрителя

- ☐ **1.1 Вступление 26 с → 8–10 с.** Крючок в первой фразе («Кто сейчас №1 — Дракон или Пират Воин? Ответ в конце»),
  быстрый тизер: три постера топ-3 под размытием, строка гербов, сразу к №15. Текст вступления переписать короче. ❓ раскрывать ли №1.
- ☐ **1.2 Нет простоя колоды.** Сейчас ~5 из 7 минут колоды стоят неподвижно (№7, №6, №5, №4 — по 18–24 с, №1 — 27 с подряд).
  Решение: «обход» — если карта не звучит дольше ~6 с, камера медленно проходит по постеру (2–3 точки, зум ~1,5,
  без подъёма карт); названные карты — как сейчас. Плюс по 1–2 ключевые карты в текст колод №7, №6, №5, №4 (из статьи).
- ☐ **1.3 Топ-3 — событие.** Перед №3, №2, №1 — заставка места 1,5–2 с: крупная золотая цифра на сукне, удар/литавра,
  пауза в голосе. Для №1 — дольше и с золотой рамкой постера. Без искр и свечений.

## Этап 2. Кадр

- ☐ **2.1 Левый нижний угол** (≈850×400 px пустого пергамента во всех 15 сценах). Блок «Матч-апы»: гербы классов
  «сильна против / слабая против» из текста статьи (данные в конфиге колоды), загораются под голос. Там же — карточка
  «упомянута, но не в колоде» (Аметистовая тревога, гигант, Наралекс) вместо того, чтобы камера их пропускала.
- ☐ **2.2 Ровная раскладка.** Левая колонка фиксированной ширины во всех сценах; постер в 6 колонок центрируется
  в правой зоне, а не прижимается вправо — текст перестанет «прыгать» между сценами.
- ☐ **2.3 Тезисы.** Минимум ~3 с между подсветками (сейчас бывает 0,6 с); поправить привязки у №12 (первый тезис
  горит 25 с), №2, №14, №5, №4, №7.

## Этап 3. Субтитры

- ☐ **3.1 Разбивка.** Две строки до ~42 знаков, выровненные по длине; куски короче ~20 знаков склеиваются с соседом;
  на экране не меньше 1,2 с; разрыв — по фразе, а не посреди («преимущество над / Друидом»).
- ❓ **3.2 Вшитые субтитры при готовом голосе:** оставить (смотрят без звука с телефона) или только файл .srt для YouTube.

## Этап 4. Звук

- ❓ **4.1 Музыка.** Сейчас два трека по 30 с по кругу — повтор каждые 57 с, ~9 раз за ролик, перепады громкости ~11 дБ.
  Варианты: ElevenLabs Music (длинные таверн-треки 2–4 мин, по одному на блок 15–11 / 10–6 / 5–4 / топ-3)
  или фонотека YouTube. Выровнять громкость по трекам.
- ☐ **4.2 Звук мест.** Мягкий удар на смене места, сильнее — на топ-3 (вместе с 1.3).
