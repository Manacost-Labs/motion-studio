# League of Legends — игровой набор

Данные, ассеты и правила для роликов по LoL. Здесь только игра: стиль (looks) и канал (brands) — отдельно.
Шаблона и сцен пока нет: сначала стиль-кадры и выбор пользователя (план этапа C).

### Статистика (винрейты, тир-листы)

- Официального агрегата нет. Кандидат — OP.GG MCP (`mcp-api.op.gg/mcp`); условия использования в монетизируемых роликах не описаны → письменно уточнить у OP.GG ДО первого тир-листа.
- Riot API: personal-ключ не для публичного использования (ролики — серая зона, не брать); production-ключ — после одобрения Riot.
- u.gg, lolalytics, op.gg не скрапить.
- **Rift Codex** (`C:/Users/zulut/Documents/lol-website`, свой сайт пользователя) — источником статистики НЕ является: это статический Next.js без своего API. Данные он берёт сам из Data Dragon, CommunityDragon и Meraki (`apps/lol/scripts/fetch-data.mjs` → `apps/lol/src/data/champions.json`, `meta.json`: версия, дата, счётчики). «Места в рейтингах» — по базовым характеристикам и формуле роста (`apps/lol/src/lib/stats.ts`), не по винрейту. Тир-лист — конструктор: расстановку делает посетитель, хранится в его браузере. Единственный маршрут — `/search-index.json` (статический индекс поиска). Годится как образец логики: КОПИРОВАТЬ с пометкой источника, не импортировать по пути.

## Нумерация патчей

Data Dragon `16.19.1` = публичный «патч 26.19»: с 2025 года публичный номер — год (15.x → 25.x, 16.x → 26.x).

- `ddToPublic('16.19.1')` → `'26.19'`, `publicToDd('26.19', versions)` → `'16.19.1'` (lol-lib.mjs). В `ids.ts` — константы `DD_VERSION` и `PATCH`.
- В ролике (заголовок, обложка, голос, описание) — ТОЛЬКО публичный номер. «Патч 16.19» — ошибка.
- Однозначные патчи пишем с нулём (`26.05`, как 25.05 в 2025). Сверено по versions.json 04.10.2026: в 2026 году версии DD идут подряд `16.1.1` … `16.19.1` (19 патчей, у каждого одна сборка `.1`, особой нумерации вроде 25.S1 нет); `ddToPublic` даёт `26.01` … `26.09`, `publicToDd` для каждой версии возвращает её же и с нулём, и без (`26.09` и `26.9`). Как сам Riot пишет 26.1–26.9 в заголовках патчноутов (с нулём или без), versions.json не показывает — сверить по патчноуту при первом таком ролике.
- Новый патч в DD появляется с задержкой: до этого `lol-data` честно берёт предыдущую версию.

## Правило цифр

Любое число в ролике (урон, перезарядка, цена, процент, винрейт, место) — только с источником, который можно открыть:
1. официальные данные: Data Dragon конкретной версии или патчноут — с номером патча;
2. статистика — только из снимка одобренного поставщика, с подписью «по данным … · ранг · патч» на экране.

Нельзя: цифры по памяти и из ответа модели; прирост силы атаки из DD (с 16.5 там 0); числа из описаний DD (там невычисленные `{{ }}`).
Нет источника — нет числа: формулировать словами («урон Q увеличен»).

## Имена и id

- В конфиге ролика — только id: `ChampionId` ('MonkeyKing'), `ItemId` (3020), `RuneId` (8112). Опечатку ловит tsc.
- На экране и в голосе — официальные имена ru_RU из `champions.ts` (Вуконг, Афелий, Мисс Фортуна, Ксин Жао). Сленг — только по решению пользователя.
- id ≠ имя: MonkeyKing — Вуконг, Nunu — Нуну и Виллумп, Renata — Рената Гласк, JarvanIV — Джарван IV.
- Предметы: в сборках брать 4-значные id. 6-значные (323003 «Посох архангела» и т. п.) — варианты; в `ids.ts` у них пометка «вариант, обычный — 3003».

## Произношение

`data/pronounce.json` — черновик, слушать через `scripts/ears.py` до озвучки.
- Имена с апострофом читаются слитно (Кай'Са → «Кайса», К'Санте → «Ксанте»), Джарван IV → «Джарван Четвёртый». Склоняемые имена даны в падежах; Бел'Вет, Рек'Сай (женские на согласную), Ког'Мао, К'Санте не склоняются.
- Апостроф прямой (`'`), как в ru_RU: с типографским `’` словарь не сработает.
- Клавиши: Q «ку», W «дабл-ю», E «и», R «ар» (или «ульта» — в тексте). Сокращения: АД, АП, АДК, КДА, ТП.
- Английские имена (Wukong, Nunu & Willump, Kha'Zix) в тексте диктора — ошибка, а не повод для словаря: писать имя ru_RU. Проверка латиницы в qa это и ловит.
- Проверка латиницы (`src/core/qa/audit.ts`) пропускает римские цифры (I, V, X: «Джарван IV») и слова из словарей pronounce. «Таам Кенч» — проверить на слух.

## Политика Riot (Legal Jibber Jabber)

Источник: https://www.riotgames.com/en/legal (раздел Legal Jibber Jabber). Ниже пересказ своими словами; сверено аудитом 04.10.2026, перед запуском канала сверить снова.

- **Обязательная оговорка** — в описании КАЖДОГО ролика. Её смысл: проект сделан по политике Riot «Legal Jibber Jabber» с использованием ассетов, принадлежащих Riot Games, и Riot его не одобряет. Заканчивается она фразой «Riot Games does not endorse or sponsor this project.» Полный английский текст скопировать со страницы политики в день запуска (с названием канала) и добавить русский перевод. Оговорка из README Rift Codex не подходит — это вариант для приложений на Riot API.
- **Можно:** монетизация рекламой YouTube (pre-roll, паузы, плашки спонсоров).
- **Музыка:** официальный плейлист Riot для авторов (Creator-Safe Playlist) и альбомы Sessions можно в монетизируемых роликах — с указанием, что музыка предоставлена Riot Games (подпись взять со страницы плейлиста). Прочая музыка и синематики Riot ловятся Content ID.
- **Коммерция:** платный доступ к контенту запрещён; сборы средств и проекты от юрлица считаются коммерческими. Модель HearthPulse (подписка Boosty) на LoL не переносится. Донаты под роликами — уточнить: исключение есть только для стримов.

## Нельзя

- Логотипы Riot — нигде в проекте. Товарные знаки Riot — не как знак своего канала или ролика.
- Товарные знаки и имена персонажей — в названии канала, доменах и аккаунтах (`legal.forbidden` бренда → `yt-qa` ❌ в имени, сайте, ссылках и подвале канала).
- Выдавать канал или ролик за официальный: «официальный», «official», «Riot Games представляет» (`legal.forbiddenInVideo` → `yt-qa` ❌ в названии, вариантах названия, тегах и хэштегах ролика). Назвать игру и чемпионов в названии, чтобы описать ролик («Гайд на Ари | League of Legends»), — описательное упоминание; окончательно решает пользователь перед запуском канала (вопрос 10 в BRIEF.md студии).
- Теги и ключевые слова: текст политики отдельно запрещает товарные знаки и названия IP Riot как ключевые слова и поисковые теги (касается tags.txt из yt-export). «League of Legends», «LoL», «Riot», «Riot Games» в тегах и хэштегах — `legal.forbiddenInTags` → `yt-qa` ❌. Имена чемпионов — тоже IP Riot; включать ли их в запрет тегов — вопрос пользователю (BRIEF.md), пока — проверка глазами.
- Платный доступ (Boosty-эксклюзивы, Patreon и т. п.) к LoL-контенту.
- Перезалив киберспорта и чужих VOD с лёгким комментарием.
- Музыка Riot вне Creator-Safe Playlist.
- Скрапинг u.gg, lolalytics, op.gg. Цифры статистики без источника и подписи. Personal-ключ Riot API для публичных данных.
- «Патч 16.x» в ролике — только публичный 26.x.
- Качать dragontail (2,6 ГБ) и тащить все сплэши в git.
- Импортировать файлы Rift Codex по абсолютному пути — только копировать логику с пометкой источника.
- Брать тёмный HUD Rift Codex как есть и строить шаблон до выбора стиль-кадров; неон, свечение хекстека, частицы, тряска, караоке-субтитры.
