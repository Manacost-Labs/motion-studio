# Витрина приёмов «Компендиума»

Витрина — композиция `yt-motion-showcase` (каждый приём движения отдельно, с подписью: имя для кода, длительность, кривая)
и `yt-depth-lab` («живой» арт). Код — `src/studios/manacost-youtube/motion-showcase/Showcase.tsx` и `DepthLab.tsx`:
витрина собрана на образце статьи Hearthstone (`games/hearthstone/fixtures`) и показывает детали игры рядом с деталями
стиля, а стиль по правилу слоёв не импортирует игру — поэтому она живёт в студии, а здесь только ссылка.

Новый приём стиля: деталь в `../parts/` и строка в `Showcase.tsx` (имя, длительность, кривая). Открыть: `npm run studio:youtube` →
папка `motion-showcase`.
