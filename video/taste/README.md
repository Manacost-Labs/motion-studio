# Вкус по направлениям: как вести записи

Вход — `../TASTE.md` (общее для всех направлений и ссылки сюда). Здесь — файл на направление:

| Файл | Направление |
|---|---|
| `hearthpulse.md` | реклама и обзоры функций HearthPulse (`hp-ads`, `hp-features`) |
| `manacost-hs.md` | YouTube Манакоста по Hearthstone, стиль «Компендиум» (`manacost-youtube`) |
| `lol.md` | YouTube League of Legends — пусто до брифа и стиль-кадров |

Новое направление получает свой файл по шаблону `.claude/skills/studio-new-direction/templates/taste.md`.

## Формат строки

Одна строка — одно решение пользователя:

| Что | Пример | Слова пользователя | Дата | Область | Статус |
|---|---|---|---|---|---|
| коротко, что именно | кадр (`qa/golden/<id>/…`, `qa/taste/…`) или файл пробы (`out/lab/…`); нет — «—» | дословно, в кавычках; нет слов — как было («выбран вариант …») | ДД.ММ | где действует: «все», «реклама HP», «YouTube Манакоста», «LoL» | `одобрено` · `проба` · `отвергнуто` · `вопрос` |

- **Статусы ведутся только здесь.** Навыки, README шаблонов и конфиги ссылаются на строку, а не повторяют «проба 03.10» у себя — иначе после отзыва обновится одно место из пяти.
- `проба` — показано, ждёт отзыва. После отзыва строка переходит в `одобрено` или `отвергнуто` (с новыми словами и датой), старый статус не держим.
- `вопрос` — решения пока нет, спросить пользователя; до ответа — не предлагать.
- Правило «для всех» записывается в `../TASTE.md` только когда пользователь подтвердил его хотя бы в двух направлениях или сказал прямо «везде».
- Эталонные кадры вкуса — `qa/taste/` (новые — в `qa/taste/<направление>/`); эталоны шаблона YouTube — `qa/golden/<id>/`.
- Изменился одобренный вид шаблона → после «да» пользователя `node scripts/yt-golden.mjs <id> --approve` (новые эталоны).
