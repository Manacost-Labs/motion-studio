# Свои записи Hearthstone

Сюда OBS пишет записи игр; клипы из них режет `node scripts/rec.mjs` (из `video/`). Сами записи и клипы в git не идут.

## Настройка OBS (один раз)

1. **Настройки → Вывод → Запись:** путь записи — эта папка (`…\Hearthpulse Ads\video\recordings`); формат записи — **«Гибридный MP4»** (только он хранит метки); качество — «Высокое» или «Неотличимое».
2. **Настройки → Видео:** выходное разрешение 1920×1080, 60 кадров/с.
3. **Настройки → Горячие клавиши → «Добавить метку главы»** — например F9.
4. Трекер колоды (HDT и т. п.) лучше выключить на время записи — иначе его придётся обрезать в кадре.

## Во время игры

Сразу **после** удачного момента — летал, большой розыгрыш, комбо, неожиданный поворот — нажать F9. Скрипт вырежет 12 секунд до метки и 3 после. Забыли нажать — не страшно: запись без меток он просмотрит сам и предложит самые активные моменты.

## Дальше

- `node scripts/rec.mjs` — новые записи → клипы в `clips/` и обзор `clips/index.md` (у каждого клипа полоска кадров).
- `node scripts/rec.mjs take <клип> --name <имя> [--trim 2-9]` — клип в ролик (`public/clips/<имя>.mp4`, подпись «Геймплей: запись Манакоста»).
- Ник соперника виден в кадре — если нужно, скажите, добавим размытие.
