Формат строки и статусы (`одобрено` · `проба` · `отвергнуто` · `вопрос`) — `taste/README.md`. Правила бренда — `BRAND.md`; здесь — вкус: как должно ощущаться.

## Общее для всех роликов

- **Плавно и мягко.** Мягкие кривые, без пружинящих отскоков. Склейки — на сильную долю музыки, текст «живой» всё время.
- **Ничего не обрезано и не прыгает.** Интерфейс сайта — целиком, без кадрирующих наездов («резко и обрезано» — отвергнуто). Текст не переносится и не дёргается во время анимации. Карты не дрожат (02.10: «карты постоянно дёргаются и дрожат» → исправлено, см. `cam-jitter.py`).
- **Нестандартные «профессиональные» приёмы — да** (02.10: перелистывание страниц — «очень интересный переход»; «мне нравятся такие нестандартные элементы… делают ролик профессиональнее»). Новые — в ручном стиле направления, показывать фрагментом.
- **Показывать до долгого рендера.** Фрагмент 10–45 с, ждать отзыва. Пользователь смотрит на телефоне и на большом экране с высокой плотностью — резкость важна (4K для YouTube).
- **«Нейросетевой почерк»** (свечения, искры, частицы, неон, тряска, блики на картах) отвергнут 29.09 («ИИ подчерк») для **YouTube Манакоста** — `taste/manacost-hs.md`. Для рекламы HearthPulse это **вопрос**: одобренная v3 построена на Embers — `taste/hearthpulse.md`. Новому направлению по умолчанию не предлагать, пока пользователь не выбрал стиль-кадры.

## Как пользоваться

1. Новый приём или правка вида → найти похожее здесь и в файле направления; если вид спорный — фрагмент пользователю до массовой правки.
2. Отзыв пользователя → строка в файл направления (что, пример, его слова, дата, область, статус). Сюда — только если правило подтверждено для всех направлений.
3. Изменился одобренный вид шаблона YouTube → `node scripts/yt-golden.mjs <id> --approve` (новые эталоны) после «да» пользователя.
